# HOME CONTINUAR ASSISTINDO


Implementar a seção Continuar assistindo da Home.

Cada item deve mostrar:
- artwork;
- título;
- episódio atual;
- progresso;
- indicador visual de progresso;
- ação para continuar reprodução.

Ordenar de acordo com o estado real de progresso/atividade.

Ao atualizar o progresso no player, a Home deve refletir o novo estado sem precisar reiniciar o aplicativo.

Não criar lógica paralela de progresso. Usar a fonte de dados existente.

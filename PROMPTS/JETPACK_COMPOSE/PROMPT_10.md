# MINHA LISTA E ESTADOS


Implementar os estados de organização da Biblioteca.

Criar filtros reais para:
- Todos;
- Favoritos;
- Assistindo;
- Completos.

Se a base existente não tiver algum conceito, derivar o estado de dados reais sem criar armazenamento redundante.

Permitir alterar favorito e estado assistido.

A interface deve seguir o padrão dos screenshots, inclusive cards/listas quando apropriado.

Garantir persistência após fechar e reabrir o app.

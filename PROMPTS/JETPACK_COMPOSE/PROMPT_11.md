# DETAILS HERO


Reconstruir a tela Details em Compose conforme o screenshot de One Piece/Frieren.

Implementar:
- imagem de capa/hero;
- botão voltar;
- ações no topo;
- título;
- gêneros;
- nota/ano/quantidade de episódios quando disponíveis;
- botão Assistir;
- botão Minha Lista/Favoritar;
- navegação interna Sobre, Episódios e outras seções somente se houver dados reais.

Usar dados da biblioteca local.

A tela deve continuar funcionando mesmo quando metadados externos não estiverem disponíveis.

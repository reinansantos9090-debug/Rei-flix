# DETAILS TEMPORADAS


Implementar a seção de temporadas e episódios.

A UI deve reproduzir o padrão visual dos screenshots:
- temporadas em cards quando existirem;
- quantidade de episódios;
- seleção de temporada;
- lista de episódios;
- thumbnail;
- número/título;
- duração;
- indicador de progresso;
- menu contextual.

Preservar o comportamento que já evita o desaparecimento de episódios.

Cada episódio precisa possuir identidade estável na composição.

Não usar clear/extend imperativo para montar a árvore Compose.

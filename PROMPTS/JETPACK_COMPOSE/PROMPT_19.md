# AJUSTES APARÊNCIA E GERAL


Migrar as configurações de aparência e gerais para Compose.

Aparência deve controlar apenas recursos realmente existentes, incluindo tema escuro quando suportado.

Geral deve expor somente configurações reais, como idioma/notificações/dados se estiverem implementadas.

As alterações devem ser persistentes.

Não criar controles que não tenham implementação correspondente.

Aplicar mudanças de tema/idioma sem quebrar a navegação.

# AJUSTES CONTA GOOGLE


Migrar para Compose a tela de conta Google apenas se a integração existente estiver funcional.

Implementar:
- estado da conta;
- sincronização de progresso;
- trocar conta;
- sair;
- estado ligado/desligado;
- mensagens de erro;
- modo offline.

A conta não pode ser obrigatória para usar a biblioteca local.

Não adicionar autenticação fictícia nem substituir a implementação existente por uma simulação.

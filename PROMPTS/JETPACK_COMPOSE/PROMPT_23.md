# NEXT PREVIOUS AUTOPLAY


Auditar e integrar os controles Next/Previous/Autoplay com a nova arquitetura.

Requisitos:
- identidade estável dos episódios;
- ordem correta;
- respeito à temporada;
- cancelamento de transições antigas;
- nenhuma ação stale;
- nenhum episódio pulado;
- nenhum episódio duplicado;
- retorno correto para Details;
- progresso salvo antes da troca.

Criar testes de regressão para os problemas históricos do ReiAnix.
